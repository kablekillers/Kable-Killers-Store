First time? Turn on ADB

  1. Settings → My Fire TV → About → click your device name 7 times until it says you're a developer.
  2. Back to My Fire TV → Developer Options → turn ADB Debugging ON.
  3. Find the IP: My Fire TV → About → Network.
  4. Add it here and tap it. On the TV choose “Always allow from this computer” → OK.
  1. Settings → System → About → click Android TV OS build 7 times.
  2. Settings → System → Developer options → turn USB debugging ON.
  3. Find the IP: Settings → Network & Internet → your Wi-Fi network.
  4. Add it here and tap it. On the TV check “Always allow from this computer” → OK.
Phone and TV must be on the same Wi-Fi. Port is 5555.
